### 📌 Featured Projects

**[Clinical Dataset EDA & Statistical Analysis](https://github.com/marepallyvaishnavigoud/clinical-dataset-eda)**
Cleaned and statistically analyzed a 303-patient healthcare dataset (UCI Heart Disease). Ran a Welch's t-test comparing heart-rate outcomes across patient groups (p = 9.106 × 10⁻¹⁴), with full documentation of assumptions and workflow in Jupyter.
`Python` `Pandas` `Matplotlib` `Seaborn` `SciPy`

**[AyurCare – Ayurvedic Healthcare Platform](https://github.com/marepallyvaishnavigoud/Ayurvedic-Healthcare)**
Full-stack platform connecting users with Ayurvedic doctors and treatments. JWT + Google OAuth auth, REST APIs, appointment booking, and cart system. Deployed on Vercel/Render.
`React` `Node.js` `Express` `MongoDB Atlas`
🔗 [Live Demo](https://ayurvedic-healthcare-khaki.vercel.app/)

**[AI-Based Skill Gap Analyzer](https://github.com/marepallyvaishnavigoud/AI-Skill-Gap-Analyzer)**
Flask app that parses resumes (PyPDF2), computes a weighted skill-match score against target roles, and generates a personalized PDF learning roadmap.
`Python` `Flask` `PyPDF2` `ReportLab`
🔗 [Live Demo](https://ai-skill-gap-analyzer-e7fa.onrender.com)

**[MyMatch – Team Matching Platform](https://github.com/marepallyvaishnavigoud)**
